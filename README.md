## The problems I like solving

I solve the everyday technology problems that quietly slow a business down: access issues, unreliable workflows, endpoint trouble, Microsoft 365 friction, unclear ownership, and fixes that were never documented.

Today, I provide independent IT support to two small businesses across Microsoft 365, user access, endpoints, applications, connectivity, vendor coordination, and secure operating practices. I pair that hands-on work with more than 10 years of leadership and high-accountability experience.

> **My goal is simple:** restore service, protect the environment, and leave behind a clear path so the next resolution is faster.

## How I work

| When I see... | My default response |
|---|---|
| A user is blocked | Restore service safely, communicate clearly, and confirm the fix |
| The same issue returns | Find the pattern, address the cause, and create a reusable runbook |
| A security change is needed | Understand the risk, plan rollback, make the smallest safe change, and validate |
| An incident is unclear | Preserve evidence, build the timeline, document decisions, and escalate early |
